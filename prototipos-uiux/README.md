# Protótipos UI/UX

Protótipos estáticos (HTML/CSS puro, sem JS) de todas as telas do Weatherly — atuais e futuras.

Abra [`index.html`](index.html) no navegador para navegar por todos.

| Arquivo | Tela | Status |
|---------|------|--------|
| `home.html` | Home (dia limpo, noite, chuva) | MVP — implementada |
| `busca.html` | Busca de cidade (resultados, buscando, vazio) | MVP — implementada |
| `estados.html` | Loading, GPS negado, erro de API | MVP — implementada |
| `detalhes.html` | Detalhes do dia (AQI, UV, sol, lua) | Roadmap |
| `radar.html` | Radar de chuva + timeline | Roadmap |
| `cidades.html` | Favoritos + comparar cidades | Roadmap |
| `alertas.html` | Central de alertas + preferências | Roadmap |
| `config.html` | Configurações (unidades, tema, viagem) | Roadmap |

Tokens em `styles.css` espelham o app: gradientes por condição (`clear-day`, `clear-night`, `cloudy`, `rain`, `storm`, `fog`), fontes DM Sans + Outfit, glass cards.
